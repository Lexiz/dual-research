# Spec 0252.1 — Refactor: delete orphaned DesignLanguageButton + ActiveRunChip declarations

> **Type:** refactoring  |  **Complexity:** S  |  **Depends on:** 0252
> **Bump:** PATCH — internal restructure, no behavior change
> **Evidence:** Spec 0252 deleted `RightCluster` (the universal-chrome cutover) — the only caller of `DesignLanguageButton` — leaving two zero-reference function declarations behind. Recorded in the 0252 handoff `## Deferred during implementation` note (`handoffs/2026-05-29-spec-0252-provider-band-comments-backfill-universal-chrome-nav.md`).

---

## 1. Current state

Two function components in `src/dual_research/ui/static/app.jsx` are dead declarations — defined but never rendered or referenced:

- `function ActiveRunChip(...)` at `src/dual_research/ui/static/app.jsx:264` (with its leading comment block from `:262`). Already dead before spec 0252; it was rendered only by the old chrome bar. Spec 0252 §2.3 enumerated five components to delete and did not name it, so it was left in place.
- `function DesignLanguageButton(...)` at `src/dual_research/ui/static/app.jsx:311`. Rendered only inside the now-deleted `RightCluster` (the logged-out chrome branch). The `git show 0dc61c5 -- src/dual_research/ui/static/app.jsx` diff shows the single `<DesignLanguageButton onClick={() => navigate('language')} ... />` call site was removed along with `RightCluster`, leaving the declaration orphaned.

Confirmation of zero call sites:

```
$ grep -n "DesignLanguageButton\|ActiveRunChip" src/dual_research/ui/static/*.jsx
src/dual_research/ui/static/app.jsx:262:// Spec 0056 SUR-06: ActiveRunChip — pill showing the short run ID in the
src/dual_research/ui/static/app.jsx:264:function ActiveRunChip({ runId, onClick }) {
src/dual_research/ui/static/app.jsx:311:function DesignLanguageButton({ onClick, active }) {
```

Only the declarations (and `ActiveRunChip`'s comment) remain — no JSX usage, no other module references. The pain: dead JSX accretes, misleads future chrome edits into thinking these primitives are live, and the 200+ spec corpus already carries enough drift. The `/language` route stays reachable via the avatar menu's "Design language" item, so deleting `DesignLanguageButton` loses nothing functional.

### User story (spec 0198 §2.3)

As a maintainer editing `app.jsx` chrome, I want the orphaned `DesignLanguageButton` and `ActiveRunChip` declarations gone, so that the file's live component set matches what actually renders and future chrome edits are not misled by dead primitives.

### Acceptance criteria (BDD)

- GIVEN `app.jsx` after spec 0252's universal-chrome cutover
  WHEN I grep the static jsx tree for `function DesignLanguageButton(` or `function ActiveRunChip(`
  THEN zero matches are returned because both dead declarations have been deleted.
- GIVEN a logged-in user on the live app
  WHEN they open the avatar menu and click the "Design language" item
  THEN the `/language` route still loads, confirming the deletion changed no rendered behavior.

## 2. Target state

Both orphaned declarations (and `ActiveRunChip`'s now-stale leading comment) removed from `src/dual_research/ui/static/app.jsx`. The surrounding chrome-history comments that already record the spec-0252 removals stay. After the change:

```
$ grep -c "function ActiveRunChip\|function DesignLanguageButton" src/dual_research/ui/static/app.jsx
0
```

No other file changes — this is a pure deletion within one file. `design-system/` is untouched because neither declaration is a design-system primitive (both are app-local chrome composites).

## 3. Stepwise migration

- **Step 1:** Delete the `ActiveRunChip` comment block + declaration (`src/dual_research/ui/static/app.jsx:262`–`:288`) — verifies via source-pattern antipodal-absence test that `function ActiveRunChip(` no longer appears in app.jsx.
- **Step 2:** Delete the `DesignLanguageButton` declaration (`src/dual_research/ui/static/app.jsx:311`–`:317`) — verifies via source-pattern antipodal-absence test that `function DesignLanguageButton(` no longer appears in app.jsx.
- **Step 3:** Re-run `grep -n "DesignLanguageButton\|ActiveRunChip" src/dual_research/ui/static/*.jsx` and confirm zero matches across all jsx files (catches any reference re-introduced elsewhere).

- [ ] Full suite `uv run pytest tests/ -q` stays green — no test referenced either symbol (both were already unrendered).
- [ ] New source-pattern test `tests/test_spec_0252_1_orphan_cleanup.py` (per spec 0206 UI test doctrine, via `tests/_ui_pattern_helpers.py`): antipodal-absence assertions that neither `function ActiveRunChip(` nor `function DesignLanguageButton(` appears in `src/dual_research/ui/static/app.jsx`, plus a positive assertion that the live `/language`-route entry point (the avatar menu "Design language" item) is unaffected.

## 5. Out of scope

**Explicit: this spec adds no new feature.** It only removes two dead function declarations. It does not touch `AllRunsChrome`, the avatar menu, the `/language` route, or any design-system primitive. Any further chrome consolidation is a separate follow-up.

## 6. Risks

- **Hidden reference via string/dynamic lookup.** Mitigated: the components are React function declarations referenced only by JSX identifier; Step 3's repo-wide grep across `*.jsx` is the guard, and a string-keyed render path does not exist in this codebase for these.
- **Missed call site in a non-jsx asset.** Low — both names are JSX components; the grep in Step 3 plus the green full suite cover it.
- **Stale comment left behind.** Mitigated by deleting `ActiveRunChip`'s leading comment block in Step 1; the spec-0252 chrome-history comments are intentionally retained as they document live removals.
