## What shipped

Agent Input tab rework with six changes. Renamed "Input" to "Agent Input" across all modal tab labels (top-level modal tabs in output/preflight modals) and left-pane sub-tabs (NegotiateLeftSubTabs in the negotiate review modal). Reordered modal tabs so Agent Input appears first (before Content) via `TABS_CANON` update from `['content', 'input', ...]` to `['input', 'content', ...]`. Entry ordering inside the Agent Input panel changed: System Prompt first (collapsed by default), User Prompt second (expanded), then remaining entries in canonical order. Input entries refactored from hand-rolled disclosure buttons to `<CollapsibleSection>` primitive (SPEC-0071). Input piece bodies now render via `<Markdown>` instead of raw `<pre>`. Empty state messaging improved to remove internal spec number references. Timeline card header renamed from "Input" to "Agent Input". New `.agent-input-entry` CSS class added to components.css. Agent Input panel spotlight added to Design Language page Component Spotlights.

### Mid-flight refinements

- **D3 (Always show System Prompt for old runs)** -- Draft proposed injecting a default system prompt from the agent's running config for pre-0033 runs. Scaled back: no reliable source for historical default prompts exists. Instead, improved the empty state message to say "Agent input bundle was not recorded for this run" without referencing internal spec numbers.
- **D6-D7 (User Prompt nested sub-sections + Child Pages)** -- Draft proposed parsing chat content for URLs/Notion links and rendering child pages as sibling entries. The input bundle data shape has no "child page" concept — pieces are keyed by role (`system`, `brief`, `d1`, `d2`, etc.) with no URL/resource metadata. Deferred entirely to a future spec that would need backend changes.
- **D13 (Aggregator investigation)** -- No backend changes made. The existing input bundle API serves the data correctly; the empty-bundle case is a legitimate pre-0033 data absence, not a bug.
