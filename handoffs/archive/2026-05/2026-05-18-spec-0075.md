## What shipped

Consumption tab agent-card restructure with four changes. Expanded agent cards reorganized into a three-zone vertical layout: data header (agent name + metrics chips + costs cluster) grouped at top, 1px divider, then bars zone (total input bar + breakdown sub-bars + output bar) at bottom. Cards grow downward on expand; total bar stays put as visual anchor while breakdown bars cascade below. Phase-label column narrowed from 160px to 100px and bar-label columns narrowed from 140px to 100px via new `--consumption-label-w` CSS custom property token, giving bars ~40px more width per card. New `.consumption-card` CSS class codified in components.css for the three-zone layout. Consumption card spotlight added to Design Language page Component Spotlights section.

### Mid-flight refinements

Decided against: the collapsed `TokenBar` component already shows a full segmented bar with per-piece breakdown + output tail + reuse overlay.
