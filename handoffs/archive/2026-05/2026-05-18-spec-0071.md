## What shipped

Timeline structural pass with six changes across two panes. New `<CollapsibleSection>` primitive added to shared.jsx — a generic disclosure component with chevron, localStorage persistence per key, and reduced-motion respect. Timeline phase headers (PhaseDivider) are now wrapped in CollapsibleSection, making each phase's cards collapsible; state persists per run+phase. Critique pane DRIFT/OPEN/RESOLVED sections similarly wrapped with collapsible headers using the same primitive. PhaseRail completed-phase labels now use `--ok` (green) color instead of dim `--fg-3` for readability. Phase header visual standout improved: `--border-2` instead of `--border-1`, fontWeight 700, and slightly wider than cards via -4px negative margins. Card base padding reduced from 12px/16px to 8px/12px for a denser timeline. Small inline badges unified to consistent fontSize 11 / padding 2px 7px.
