## What shipped

Fixed a P0 white-screen regression that blocked every run-detail page since v0.63.0. A JSX comment (`{/* */}`) was placed inside a prop expression slot (`left={...}`) in `run-detail.jsx` during SPEC-0070, causing a Babel parse error. The comment was moved to JSX children position above the `<PaneHeader>` tag. Also shipped a regression test (`tests/test_ui_jsx_syntax.py`) that parametrically scans all 18 JSX files for the same pattern class to prevent recurrence.
