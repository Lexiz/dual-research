### Mid-flight refinements

- **D2 (smaller pills)** -- Draft proposed dropping height to 20px and font to 10.5px. Kept both at existing values (height already 20px in `.sb`, font 11px in legacy StatusBadge) since they already look proportional. The visual improvement comes from the uniform width, not smaller size.
- **D3 (column gap)** -- Draft proposed bumping grid column-gap. Shipped as `paddingLeft: 8` on the topic cell instead, which is more targeted and doesn't affect other columns.
- **D6 (chrome tabs)** -- Draft proposed fixed `min-width: 110px`. Shipped as simply making All Runs use `size="sm"` like Compare/Search already do -- the Tab primitive handles sizing consistently.
- **D10 (AppVersionChip)** -- Draft proposed `<Chip size="xs">`. No `xs` size exists; shipped using standard `<Chip>` with smaller font-size in style prop. Adding a new `xs` variant was unnecessary complexity.
- **D13 (attention headers)** -- Kept the count badge. It provides scan-value when multiple attention runs exist.
