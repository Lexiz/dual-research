### Mid-flight refinements

- **D2 (Modal refactor)** -- draft proposed a `width` prop override. Dropped in favour of CSS-class variants (`is-split` sets max-width 1300px). The `accent` prop is removed; agent-color left border is now controlled by `agent='a'|'b'` which maps to CSS classes `.is-a`/`.is-b`. Existing callers that passed `accent` are migrated to `agent`.
- **D3 (Modal migration)** -- the existing `tabs` prop is preserved but now renders via `<TabGroup variant="line">` + `<Tab>` instead of inline-styled buttons. Badge rendering preserved via inline span within Tab children.
- **D5 (RoundScrubber)** -- draft mentioned "first/last jump" buttons. Simplified to just prev/next arrows + clickable round pills, which covers the use case without extra chrome. The scrubber finds available rounds by scanning the timeline for items matching the current agent + phase.

## Risks the next spec should know about

- **Component-level invariants preserved:** 5-state ReconcileChip untouched. PhaseRail untouched. BlockingItemCallout untouched.
