### Spec 0039 — Cost-pipeline integrity (0.35.0 → 0.37.0, skipped 0.36.0 per user)

3. **Web-search fees missing from headline.** Reversed spec 0031 D7. New `compute_full_cost` stamps every persisted `cost_usd`; `compute_token_cost` is the per-token helper used for the breakdown.

Also:

- `D3`: aggregator transcript-primary + dedup-by-`label`-latest (parse-error retries replayed the same `turn_ended` event; partner-vetting had every `phase4-r*-*` label twice).
- `dual-research recompute-costs [--run | --all] [--push] [--dry-run]` backfill subcommand. Backs up the original to `metrics.json.pre-0039.bak`; idempotent.
- All 10 local runs + Supabase backfilled. Partner-vetting: $2.45 → $9.86.
- 22 new tests across pricing / persistence / aggregator / audit.

**What's permanently lost on old runs:** the per-TTL cache-write split (pre-0039 transcripts only carry the aggregate `cache_write_tokens`). ### Spec 0041 — Critique classification + resilience + sentiment (0.38.0 → 0.39.0)

[PR #42](https://github.com/Lexiz/dual-research/pull/42). User flagged a real semantic mismatch on Phase 4: timeline showed `APPROVED · 0 issues` while critique pane showed `74 Q · 61 open`. Both true; they were measuring different things. Four items:

1. **Parser splits `kind="issue"` / `"comment"` / `"question"`** instead of bucketing all three under `"question"`. The protocol uses three distinct sections (`## Issue ledger (delta + currently open)`, `## Comments on the current draft`, `## Open questions for {other}`) with different closure semantics; the UI now matches. Parser also gains a bold-heading entry detector since Claude's Issue ledger uses `**C-1** — open — ...` heading style instead of numbered lists.
2. **`reconstruct_issues` reads the agent's own `open` / `resolved` / `non-blocking` markers** inside each ledger entry as canonical status (matches the agent's `OPEN_ISSUES: N` end-of-turn counter the timeline already used). No cross-round positional-match heuristic for issues — they close when the drafter's revision incorporates the fix, not when an `## Answers to:` line appears. ID-token dedup (`C-1`, `OAI-3`, `D-5`) catches the same issue across rounds even when wording shifts.
3. **`useLiveRun` retry-before-error** — 3-attempt threshold before surfacing the error screen; once `run` is non-null, transient failures never overwrite it. First-load pacing: 1s / 2s / 4s before 5s steady-state. Fixes the "Could not load run · HTTP 502" flash on cold-start.
4. **Sentiment composer expanded to every phase with bold sentiment lead** (`**Positive —**` / `**Cautious —**` / `**Critical —**` / `**Mostly positive —**` / `**Solid —**` / `**Done —**`). Pre-spec Phase 0 / 1 / 3 / 5 returned `''`. Bold inline via `renderInlineBold`. Card body hard-truncates at 70 chars before ellipsis.

Plus the UI rework: `Run.issues` + `Run.comments` arrays, four-way type filter (`All / Issues / Questions / Disagreements / Comments`), new `IssueCard` + `CommentCard`, Summary tab gains `I raised / I resolved / I still open` + `C noted` columns.

Partner-vetting Phase 4 now reads `30 I (30 resolved · 0 open) · 0 Q · 0 D · 33 C` — reconciling with the timeline's `0 issues + APPROVED`.

6 new tests in `tests/ui/test_issues.py` + `test_questions.py`. 610 total green.

## Workflow (per [CONTRIBUTING.md](../CONTRIBUTING.md))

```
spec → branch → implement → tests + preview-verify → version-bump →
CHANGELOG + VERSION_NOTES → PR (admin squash-merge) → fly deploy → STOP
```

Per-spec discipline:

- Copy `specs/TEMPLATE.md` → `specs/NNNN-<slug>.md`. Front-matter: `status: in-progress`, `target-version`, `created`, `pr: ""`.
- Branch: `spec/NNNN-<slug>` (matches filename).
- Version bump table: `bug → PATCH`, `new-feature → MINOR`, `breaking → MAJOR`. Pre-1.0 the spec author can deviate (specs 0039 + 0041 both bumped MINOR with label `bug` for structural changes; document in D14).
- CHANGELOG: move `[Unreleased]` to a versioned heading. New `[Unreleased]` placeholder.
- `VERSION_NOTES` at the top of `how-it-works.jsx` for user-visible changes.
- PR: `gh pr create --label "spec/<label>" --title "Spec NNNN — <title>" --body ...`. Use heredoc for the body.
- Merge: `gh pr merge <PR#> --admin --squash --delete-branch`.
- Deploy: `fly deploy`. Verify with `curl https://dual-research-alex.fly.dev/api/health`.
