# Spec 0229 — Enforce addressee-obligation invariant + codify carve-out-disposition convention

Deployed to https://dual-research-alex.fly.dev/ — `/api/health` returns `{"ok":true,"version":"1.48.0","backend":"supabase"}`.

## What landed

- **`apply_turn` addressee-obligation check** — at the end of every parsed turn whose `parsed.status == "AGREED"`, the post-turn ledger is scanned for entries where `ent.raiser != agent AND ent.current_state == OPEN`; one `ProtocolViolation(violation_code="agreed_with_open_addressed_items", op_kind="agreed", expected_state="addressed")` per blocking item is appended. ADDRESS-then-AGREED in one turn stays silent because the ADDRESS block flips the item to `addressed` BEFORE the obligation check runs (R1 mitigation, verified by `test_address_then_agreed_in_one_turn_is_silent`).
- **Gate-only demotion via effective-status fields** — `RoundResult` grew `effective_claude_status` / `effective_openai_status` fields (default `None`). New helper `_effective_status_for(agent=, self_reported=, violations=)` maps `AGREED → IN_PROGRESS` when a matching `agreed_with_open_addressed_items` violation fired for that agent this round; passthrough otherwise. `process_round_end`, `run_round`, `check_convergence`, `should_urge_closeout`, AND the substantive-convergence escape valves in both [`deep_research.py`](src/dual_research/orchestrator/deep_research.py:1029) and [`dr_run.py`](src/dual_research/orchestrator/dr_run.py:478) consume the effective status. The agent's self-reported status stays on the dataclass for the diagnostic trail.
- **Closeout-request prompt extension** — [`closeout_request_section`](src/dual_research/protocol/prompts.py:1593) gained an `addressed_at_me_items: list | None = None` parameter. When non-empty, the rendered section grows an "Addressee-obligation" block naming each addressed-at-me item with the literal "before declaring AGREED" instruction. Empty / None → no block (back-compat). [`_build_closeout_request_text`](src/dual_research/orchestrator/deep_research.py:275) now computes both lists (`owned` = `ent.raiser == agent`; `addressed_at_me` = `ent.raiser != agent AND State.OPEN`) and threads both through.
- **Verifier I2.4 handled-vs-unhandled refactor + severity flip** — [`_check_i2_4`](src/dual_research/contract/verifier.py:533) now indexes `agreed_with_open_addressed_items` ProtocolViolations by `(phase, round, agent)` scope; for each AGREED-while-owing turn, HANDLED (matching PV exists) passes vacuously, UNHANDLED (no matching PV) fails citing the addressed-at-me item id. Severity flipped from `reporting` to `gating`. Anchor baselines regenerated: clean reference → `gating/pass` (vacuous — no offending instances); dead primary + dead secondary → `gating/fail`. Dead primary's evidence list contains all four addressed-at-openai items (`D-plan-c-02 / D-plan-c-04 / D-plan-c-05 / Q-plan-c-01`).
- **`ProtocolViolation` docstring** at [`src/dual_research/events/types.py:503`](src/dual_research/events/types.py:503) extended with the 9th code (`agreed_with_open_addressed_items`) and a paragraph explaining it's the runtime counterpart of I2.4.
- **CLAUDE.md gains the "Carve-out follow-ups must triage at carve-out time" subsection** nested under "Contract-changing specs are not `bug`s". `disposition:` (`ship` / `defer` / `archive`, default `archive`) and one-sentence `disposition_reason:` required on every carve-out; only `disposition: ship` reaches `/dev-next`.
- **Version 1.48.0** — `__init__.py` + `pyproject.toml` + `uv.lock` + `CHANGELOG.md` entry. `version-notes.json` regenerated.
- **28 new tests** at [`tests/test_spec_0229_addressee_obligation.py`](tests/test_spec_0229_addressee_obligation.py) covering runtime emission, ADDRESS-then-AGREED silence, two-blocking-items per-item granularity, non-AGREED-status passthrough, own-items / addressed-state exclusions, the effective-status helper (demote / passthrough / non-addressee-code), `process_round_end` round-result wiring (demoted + clean), closeout-prompt rendering (both shapes with explicit-None and default-omitted back-compat), the handled-vs-unhandled detector (HANDLED via PV / UNHANDLED no PV no convergence / UNHANDLED no PV with convergence / not_applicable), dead-primary fixture evidence-citing assertion, clean-anchor passes, severity-flip lock-ins across all three anchor fixtures, version + CHANGELOG + CLAUDE.md smoke checks.
