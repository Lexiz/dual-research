# Spec 0203.2 — Cycle-mutable status readers: queue-state overlay in `current_queue` + supervisor (v1.43.2)

Shipped in one session via a manually-driven `/dev-next` lifecycle. The picker bug this spec fixes is the same bug that blocked `/dev-next` from auto-picking 0203.2 — chicken-and-egg, so the operator drove the cycle by hand exactly once. After this lands, `current_queue()` correctly returns `0204` as rank 1 (verified live).

## What landed

### §3.1 — `current_queue` overlays queue-state

[`scripts/spec_lifecycle/pick_next_number.py:130-149`](scripts/spec_lifecycle/pick_next_number.py) — `current_queue` now reads `dashboard/queue-state.json` via `read_state(repo_root)` and prefers its `status` over frontmatter when present. Pre-fix the picker handed back deployed specs as the queue head because frontmatter `status` is frozen at `queued` post-spec-0202. Defensive fallback to frontmatter when `queue-state.json` is missing or has no entry for the spec — same shape as `render_dashboard.py` and `functions/api/data.js`.

### §3.3 — `_read_spec_status` overlays queue-state

[`scripts/queue_drain_supervisor.py:141-171`](scripts/queue_drain_supervisor.py) — same overlay shape. Pre-fix this function always returned `"queued"` post-0202, making the supervisor's between-iterations resume-detection branch dead code. Production has not observed the regression because no L-spec has been drained through `/dev-queue-run` yet — spec 0203 was driven interactively. After this ships, `/dev-queue-run` can correctly re-pick a checkpointed L-spec across iterations.

### §3.4 — `_find_resume_target` overlays queue-state

[`scripts/queue_drain_supervisor.py:312-342`](scripts/queue_drain_supervisor.py) — same overlay shape, with `read_state` hoisted outside the loop for `O(1)` per-spec lookups. Pre-fix this function unconditionally returned `None` because the `!= "in_progress"` filter rejected every spec (frontmatter always `queued`). After this ships, the supervisor's pre-flight resume scan correctly finds stale checkpoints from prior aborted drains.
