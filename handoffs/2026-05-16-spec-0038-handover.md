## What Spec 0038 builds

Three observable signals on the UI plus one carryover layout fix the user asked for after Spec 0035:

1. **`🔎 N` chip** on every collapsed `ArtifactCard` whose turn fired web search (next to existing token + cost chips). Quiet when no audit data for that turn.
2. **One-line gist** on expanded cards: `Pulled M results across N queries · click to inspect →`. Provider-aware copy when OpenAI returned no `consulted_sources`.
3. **New `Web Search` tab** on every full-view modal — per-query accordion, per-result cards (URL/title/host, `page_age` for Anthropic, `[cited]` tag on cited URLs), Anthropic-only `cited_text` monospace blocks below each citation, hallucinated-citation warnings in three places (tab badge, per-query header dot, banner inside the tab with the offending URL listed).
4. **Session-level `RunSearchSummary` chip** in the run-detail header: `🔎 N · M URLs · ⚠ K unmatched`. Click jumps to the first flagged card.
5. **GPT pill alignment fix**: currently Claude is right-aligned on the `PaneHeader` (row 1) and GPT is left-aligned on the `PaneToolbar` (row 2). User wants both right-aligned so they form a vertical column. Pure JSX reorder of the `PaneToolbar` children: `[live-count chip] [flex] [TimelineTabs] [AgentStrip gpt]`.

All design decisions, file-touch list, test plan, and risks are in the spec doc. Read it before implementing.

## Where the implementation patterns come from

Spec 0033 is the template for almost everything frontend in this spec:

- `useInputBundle` ([src/dual_research/ui/static/live-data.jsx:249](../src/dual_research/ui/static/live-data.jsx#L249)) → mirror as `useSearchBundle`.
- Existing inline `useInputIndex` pattern → extend with `useSearchIndex(runId)` returning a `Set<string>` of available turn-keys; the server's `/searches/index` endpoint gains an optional `?include=summary` query param so the per-card chip can render counts without fetching every bundle.
- `InputTabContent` + `InputSection` (run-detail.jsx around line 2801-2838) → mirror as `WebSearchTabContent` + `QueryGroup` + `ConsultedSourceCard`.
- The tab strip pattern (`tabs: [{ name, content, badge? }]`) is used on every full-view modal — same pattern for adding `Web Search`.

The agent-pill alignment lives in `run-detail.jsx::Timeline` toolbar (around lines 375-394). Change is in the order of children of `<PaneToolbar>`, no CSS additions.
