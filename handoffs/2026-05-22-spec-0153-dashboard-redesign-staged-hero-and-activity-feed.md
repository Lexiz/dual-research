# Handover — Spec 0153 — Dashboard redesign — DS primitives, staged hero, activity feed (v1.18.0)

- **Date:** 2026-05-22
- **PR:** [Lexiz/dual-research#176](https://github.com/Lexiz/dual-research/pull/176)
- **Merge commit:** `a524d69`
- **Cycle time:** ~21 minutes (started 11:52:51Z, deployed 12:13:34Z)

## What landed

- **Renderer rewrite.** `scripts/spec_lifecycle/render_dashboard.py` now emits the new design-system-native layout from spec 0153 — page header with live-version chip, idle-or-inflight hero, pipeline strip, rolling-10 metrics, dense queue table, 24-hour activity feed, drafts surface, full spec catalog, footer.
- **Stage helper.** `scripts/spec_lifecycle/stages.py` exposes `compute_stages(spec_id, events, failure_step=None, now=None) -> tuple[list[StageState], list[str]]`. The eleven canonical stages mirror the `/dev-next` cycle 1:1. Aliases (`pre-flight`/`preflight`, `tests`/`test`, etc.) resolve to the right index for `failure_step`. Unknown event step names come back in the second tuple element so the renderer can warn in the build log.
- **Event emissions across the cycle.** `~/.claude/skills/dev-next/SKILL.md` now calls `append_event.py` at all eleven stage transitions: `preflight_ok`, `handoff_read`, `spec_read`, `reconcile_complete` (or `reconcile_failed`), `in_progress`, `branched`, `implement_complete`, `tests_green` (or `tests_failed`), `pr_opened`, `merged`, `deployed`, `handoff_written`. This cycle (0153) emitted the full set so the dashboard timeline has real data going forward.
- **Asset copy.** The renderer copies `design-system/assets/styles/tokens-and-primitives.css` → `tokens.css` and `composed-components.css` → `components.css` into the output directory at build time, and writes a new ~300-line `dashboard.css` for page chrome. Inline `<style>` blocks in HTML are eliminated. If `design-system/` moves, `copy_design_system_assets()` raises a clear `FileNotFoundError`.
- **Version bump.** `pyproject.toml` and `src/dual_research/__init__.py` → `1.18.0`.
