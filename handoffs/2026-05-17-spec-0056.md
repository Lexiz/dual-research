### Mid-flight refinements

- **D1 (Chrome right cluster)** -- draft proposed wrapping everything in `<TabGroup variant="solid">`. This would be semantically wrong since TabGroup uses `role="tablist"` and most controls (ConnectionPill, ThemeToggle, AvatarMenu) aren't tabs. Instead, only HowItWorksLink was migrated to the Tab primitive; other controls keep their utility styling with consistent visual patterns.
- **D7 (AgentStrip adoption)** -- the bespoke AgentStrip used `composeAgentActivity` to render a live dot + activity phrase in the right zone. The shared AgentStrip primitive from shared.jsx renders a simpler `<SB>` by default. Used the `right` prop to pass the custom activity phrase content, preserving the existing rich display.

This attribute doesn't currently exist on critique cards -- the callout renders correctly (shows counts) but the click-to-jump will no-op until a future spec adds the data attribute. Not a blocker; the callout's primary value is the attention count display.
