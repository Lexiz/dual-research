## What shipped

Developer-experience infrastructure: a stable git worktree helper that lets the user run CLI invocations (`uv run dual-research --notion <url>`) from `~/dual-research-stable/` while the autonomous orchestrator cycles through feature branches in the primary `~/dual-research/` checkout. Ships a bash bootstrap script (`scripts/setup-stable-worktree.sh`) that creates a `stable` branch at current `main`, adds a worktree, and runs `uv sync` inside it. Includes a `Makefile` with a `make stable-worktree` convenience target, a CONTRIBUTING.md section documenting the parallel-run pattern and roll-forward workflow, a README pointer, and a CI `bash -n` syntax check step. No UI changes, no cache-bust, no VERSION_NOTES — this is purely developer tooling.
