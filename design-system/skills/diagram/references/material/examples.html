Deliverable 06 · Canonical worked examples · Material mode

Eighteen anchor SVGs — nine templates × two themes — of the same proposal in Material vocabulary.

Each template gets one canonical light+dark pair of the "Partner Vetting" proposal, built only from this mode's foundations, components, icons, and connectors. Compare a Material example side-by-side with its Pixel sibling in pixel/examples.html — the structure is identical; the visual language differs.

Generation note. The system-context anchor pair was hand-built in P2; the remaining 16 were transformed from their Pixel counterparts via mechanical token substitution (canvas, surface gradients, ink ladder, accent, shadow flood, type family). Layout, geometry, arrows, and icon paths are preserved unchanged. A future polish pass can redraw inline icons in the M3-outlined style documented in icons.html.
